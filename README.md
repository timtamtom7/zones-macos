# Zones

A world clock for the macOS menu bar with time-zone comparison.

## What it does

- Multiple zones
- time conversion
- side-by-side comparison
- weather
- clock formats

## Targets

- macOS menu bar

## Structure

Key types:

- ``CityStore``
- ``TimeFormatterService`/`ClockFormatService``
- ``WeatherService``
- ``CompareZonesView``
- ``TimeConverterView``
- ``ZoneRowView``

The most conventional macOS utility in the batch — a menu bar popover with a list of zones.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
